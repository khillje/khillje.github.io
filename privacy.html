Privacy policy

Smart Wall is operated by a household for its own smart calendar and home monitoring. It is not offered as a public camera or calendar service.

Google and Nest data accessed

With the account owner’s authorization, the application accesses selected Nest device information, such as device names, identifiers and supported capabilities; doorbell chime events and their timestamps; and temporary stream connection details. It receives camera video to display a periodic still image or a brief live doorbell view. The stream negotiation requests receive-only audio and video; playback is muted. The application does not request access to the display device’s microphone or webcam.

The Nest permission used is Google’s Smart Device Management scope. An existing Google Cloud Pub/Sub subscription delivers device events using separate subscriber credentials.

Use, transmission and sharing

Nest data is used for the household display, camera connection management, event deduplication and recovery. The application exchanges authorization and device requests with Google and receives media through the Nest/WebRTC connection. Connection negotiation involves Google/Nest infrastructure and network addresses; this is not an offline-only feature.

The reviewed Nest code does not upload snapshots to this website, advertising services or analytics services. The operator does not sell Nest data, use it for advertising or use it to train AI models. Other calendar and dashboard integrations have their own service providers; Nest media is not included in those integrations by the reviewed camera code.

Camera images and retention

The cabin feature draws a decoded frame into the display’s browser canvas and normally attempts a refresh every five minutes when permitted. The last successful image can remain visible if a later refresh fails. This image is retained in the page’s memory until replaced or the page is closed or reloaded; it is not a historical image archive.

The doorbell feature normally displays a live view for up to 60 seconds. It closes playback resources when the view ends or a higher-priority display takes over. Failures can prevent immediate confirmation of cloud stream cleanup, so the application retains cleanup status and may block further camera sessions pending review.

The reviewed Nest code does not explicitly save image files or video recordings to disk. Browser, operating-system and Google-managed data handling are separate; the operator does not promise that all data is erased from every cache or backup immediately. Existing Google Home/Nest recording and retention settings remain controlled by Google and the account owner.

Credentials and local operational records

OAuth client information and refresh tokens are kept outside shared application code. Windows stores the refresh token and client secret using Windows account-bound DPAPI protection. The Raspberry Pi uses an external JSON credential file protected by filesystem permissions; that file is plaintext, not application-encrypted. Access tokens are cached in the application process’s memory.

Separate Google Cloud subscriber credentials are stored outside shared code. Local records include hashed doorbell event identifiers with timestamps and camera cleanup status. Doorbell hashes are pruned during event processing using an approximately one-day age limit and a size limit; inactive files may remain longer. Cleanup status remains until resolved or reviewed. These records do not contain saved camera frames.

The operator maintains private backups, including encrypted backup archives. Backup retention is manual, without an automatic deletion deadline. Copies of credentials or operational records in backups can remain after live files change. Access to a Windows account, Raspberry Pi account or backup can expose the data available to that account.

Control, deletion and contact

The account owner can withdraw device access through Google Nest Partner Connections Manager and review connected applications through Google Account connections. Removing local files alone does not revoke Google authorization.

To remove locally held information, the household operator can stop the relevant integration and remove its credentials and operational records after reviewing cleanup requirements. Deleting retained backup copies requires a separate deliberate action. Reloading the display clears the current page’s in-memory image; it does not delete Google’s recordings.

For privacy or deletion requests, contact the household operator directly or use the existing user support email displayed on the application’s Google authorization screen. This private household application has no public registration or support portal.

This informational website

These pages contain no login, camera media, calendar feeds, tracking scripts, advertising, forms or application cookies. The website host processes ordinary web requests, including visitors’ IP addresses. If hosted on GitHub Pages, IP addresses are logged for security purposes under GitHub’s privacy statement. The public website is separate from the household display and never needs its credentials.
